# Barbellsoft Homebrew tap

Free tools from [Barbellsoft](https://barbellsoft.com).

```
brew install --cask barbellsoft/tap/chatda
```

| Cask | What it is |
|---|---|
| `chatda` | [Chatda](https://barbellsoft.com/chatda/): search files by name and by the text inside documents |

The apps are not signed or notarized by Apple yet, so the casks remove the macOS quarantine flag after installing. Chatda updates itself after you install it.
